💼 Job Application Tracker

A simple and interactive Job Application Tracker built using Python, Streamlit, SQLite, and Pandas. This application helps users manage job applications, monitor their application status, and view basic application analytics in one place.

🚀 Live Demo

👉 "Click Here to View Live Application" (https://vedha135-job-application-tracker-app-cbajlg.streamlit.app/)

📌 Project Overview

Keeping track of multiple job applications can be difficult. The Job Application Tracker provides a simple interface to record applications, update their status, and monitor progress.

✨ Features

- Add new job applications.
- Store application details in an SQLite database.
- View all saved job applications in a table.
- Update the status of existing applications.
- Track application statuses such as Applied, Interview, Selected, and Rejected.
- View total application and interview counts.
- Visualize application status distribution using a chart.

⚙️ Installation and Setup

Follow these steps to run the project locally.

1. Clone the repository

git clone https://github.com/vedha135/Job_Application_Tracker.git

2. Navigate to the project folder

cd Job_Application_Tracker

3. Install the required packages

pip install -r requirements.txt

4. Run the application

streamlit run app.py

The application will open in your browser at:

"http://localhost:8501"
